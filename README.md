# Minecraft MOTD-Generator

Gestalte die MOTD deines Minecraft-Servers mit Farben, Fett und Kursiv, sieh die Vorschau und kopiere die fertige Zeile für die server.properties.

**Online nutzen:** [Minecraft MOTD-Generator](https://ventrohosting.com/tools/minecraft-motd-generator) · Demo: https://dannytheone.github.io/minecraft-motd-generator/

## Funktionen

- Zwei Zeilen mit Farben, Fett, Kursiv und Hexfarben (&#RRGGBB)
- Live-Vorschau wie in der Serverliste (Näherung)
- Fertige Zeile für die server.properties zum Kopieren

## English

Minecraft MOTD generator: design the two-line server list description with colors, bold, italic and hex colors, preview it and copy the ready server.properties line.

Use it online: https://ventrohosting.com/tools/minecraft-motd-generator

## Selbst hosten

Statische Seite ohne Build-Schritt und ohne Abhängigkeiten: `index.html` und `tools.js` auf einen beliebigen Webserver legen oder GitHub Pages aktivieren. Alles läuft im Browser, es werden keine Daten gesendet.
